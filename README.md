# 🌌 Black Hole Simulator

An interactive black hole gravity simulation built from scratch.

## What is this?
A real-time simulation where 150 stars get pulled into a black hole by actual gravity math. Click anywhere to move the black hole and watch the stars chase it.

## What I built
- Stars with random positions and velocities
- Real gravity using Pythagorean theorem (same math as actual physics)
- Stars change color based on distance from black hole
- Trail effects and glow effects
- Animated golden accretion disk (the ring around the black hole)
- Click to move the black hole

## What I learned
- HTML Canvas for real-time animation
- JavaScript game loops using requestAnimationFrame
- Physics simulation (gravity, velocity, distance)
- Visual effects (trails, radial gradients, HSL colors)
- C++ fundamentals (structs, vectors, gravity math) — the logic was first built in C++ then translated to JavaScript

## Tech Stack
- C++ (logic building)
- HTML / CSS / JavaScript (visual simulation)
